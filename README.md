# HadeKamory

Aplikasi Android **non-UI** (tanpa antarmuka pengguna) untuk mematikan layar smartphone hanya dengan satu klik pada ikon aplikasi.

Dibuat oleh **Banghans** sebagai alternatif praktis untuk mematikan layar tanpa perlu menekan tombol power fisik.

---

## 💡 Tentang Aplikasi

HadeKamory adalah aplikasi ringan yang berfungsi sama seperti aplikasi **Layar Kunci** pada umumnya. Ketika ikon aplikasi ditekan, layar smartphone akan langsung mati.

Aplikasi ini **tidak memiliki tampilan (UI)** sama sekali. Tidak ada menu, tidak ada tombol, tidak ada pengaturan. Cukup klik ikon, layar langsung mati.

---

## ⚡ Cara Kerja

1. Pengguna menekan ikon **HadeKamory** di layar utama.
2. Aplikasi langsung memerintahkan sistem Android untuk mematikan layar.
3. Layar mati seketika.
4. Tidak ada tampilan tambahan dari aplikasi.

---

## ✨ Keunggulan

- **Tanpa UI** — tidak ada tampilan yang mengganggu
- **Ringan** — ukuran file kecil, tidak membebani sistem
- **Cepat** — sekali klik, layar langsung mati
- **Sederhana** — tidak perlu pengaturan rumit
- **Universal** — kompatibel dari **Android 1 hingga Android 14**
- **Praktis** — membantu saat tombol power fisik sulit dijangkau atau bermasalah

---

## 📱 Cara Menggunakan

1. Install APK **HadeKamory.apk** dari halaman Releases.
2. Setelah terinstall, buka daftar aplikasi di HP kamu.
3. Tekan ikon **HadeKamory**.
4. Layar akan langsung mati.
5. Selesai. Tidak ada langkah tambahan.

> **Tips:** Kamu bisa menambahkan ikon HadeKamory ke layar utama (home screen) agar lebih mudah diakses.

---

## 🧠 Tujuan Pembuatan

HadeKamory dibuat untuk membantu pengguna smartphone yang:
- Tombol power fisiknya rusak, macet, atau sulit ditekan
- Ingin cara cepat mematikan layar tanpa menekan tombol
- Membutuhkan alternatif aplikasi Layar Kunci yang lebih ringan

Biaya perbaikan tombol power bisa jadi kendala. Karena itu, HadeKamory hadir sebagai solusi perangkat lunak yang sederhana, gratis, dan bisa digunakan siapa saja.
